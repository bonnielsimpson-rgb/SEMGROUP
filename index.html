This tool helps you organize students into small groups while considering scheduling needs and preferences. Your student information saves automatically. You can leave and return later using this same computer and browser.

Getting started: 1. Add students and their time zones → 2. Set group preferences → 3. Create groups → 4. Keep the groups you choose.
